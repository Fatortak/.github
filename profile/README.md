# Fatortak

Arabic-first, open-source business OS for MENA: invoicing, accounting, HR and project management.

[Main repository](https://github.com/Fatortak/Fatortak_Software) · [Website](https://fatortak.rabbeh.com/) · [Documentation](https://github.com/Fatortak/Fatortak_Software/tree/main/docs) · [Contributing](https://github.com/Fatortak/Fatortak_Software/blob/main/CONTRIBUTING.md)

## What's inside

- Invoicing, quotations and customer management
- Accounting, expenses and financial reports
- HR, attendance and payroll
- Projects, tasks and team collaboration
- Arabic/English RTL interface
- Self-hostable: .NET 8, SQL Server and React
